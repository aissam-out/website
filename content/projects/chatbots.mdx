A chatbot that cannot touch your systems is a FAQ with extra steps. This project is the other kind: WhatsApp and Messenger agents wired to a backend.

[chatbot](https://github.com/aissam-out/chatbot) covers:

- Twilio for WhatsApp
- Dialogflow for intent and entities
- Flask as the webhook
- Firebase when you need a live store

The long-form walkthrough is [A guide to building WhatsApp chatbots using Dialogflow and Firebase](/articles/whatsapp-chatbots).

I built this class of system for e-commerce and ops work at MonarkIT. The repo is the public, stripped-down version of that pattern.
