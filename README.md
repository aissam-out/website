# Epistemic Noise

Personal site for Aissam Outchakoucht: two-minute notes on building AI systems, projects, essays, and technical writeups.

```bash
npm install
npm run dev
```

Content lives in `content/{reads,thoughts,articles,projects}` as MDX.

To regenerate the 2-minute reads from the old Python backend:

```bash
npm run migrate:reads
```
